Security & Access Control

Document-level authorization enforced before LLM context assembly

ACL Enforcement Flow
👤 User Request
↓ JWT Bearer Token
🔑 Microsoft Entra ID
Validates token, extracts group claims
↓ {user_groups: ["HR","ALL"], department: "HR"}
⚡ FastAPI Route
Passes claims to retriever
↓ pre-retrieval filter
🔍 Azure AI Search
OData filter: access_groups/any(g: g eq 'HR' or g eq 'ALL')
↓ ONLY authorized chunks
📋 Context Builder
Unauthorized documents NEVER enter prompt
↓
🤖 Azure OpenAI
Sees only authorized content
↓
✅ Authorized Answer

Security Principles
🔐
Least Privilege — Users see only documents matching their group claims
🛡️
Pre-LLM Enforcement — ACL is applied at retrieval, not after generation
🔑
Key Vault — All secrets in Azure Key Vault, never in code or env files
🎭
Managed Identity — App Service uses MI to access Azure resources without API keys
📝
Audit Logging — All requests logged with RequestID, user group, document accessed
