# RAG System Evaluation Reports

Contains performance, precision, and latency evaluation details comparing baseline RAG to improved hybrid models.

## Metrics tracked:
- **Retrieval Performance**: Hit@1, Hit@3, Hit@5, Recall@K, MRR.
- **Generation Quality**: Groundedness, correct citations, hallucination rate.
- **System Overhead**: Chunks processed, prompt/completion tokens, latency (ms).
